概述

数字逻辑电路是一个可以处理离散值变量的网络，其中包括：

  • 一个或多个离散值输入端
  • 一个或多个离散值输出端
  • 描述输入和输出关系的功能规范
  • 描述当输入改变时输出响应延迟的时序规范

电路由结点（nodes）和模块（elements）组成。

  • 结点：一段导线，通过电压传递离散值变量：
    • 输入结点：接收外部的值（图中的 $A$，$B$，$C$）
    • 输出结点：输出值到外部（图中的 $Y$，$Z$）
    • 内部结点：不属于以上两者的结点（图中的 $n_1$）
  • 模块：一个带有输入、输出、功能规范和时序规范的电路。

每一个模块本身都是一个电路（如图中的 $E_1$、$E_2$、$E_3$）。

逻辑门和数字抽象

逻辑门是最简单的数字逻辑电路，它们可以接受一个或多个二进制输入，并产生一个二进制输出。它可通过带有输入和输出的专门符号进行图形化表示，通常输入画在左边（上面），输出画在右边（下面）。

输入和输出之间的逻辑有两种描述方式：

  • 真值表（Truth Table）：左边列出输入，右边列出对应的输出。
  • 布尔表达式（Boolean Equation）：基于二进制变量的数学表达式。

多输入的逻辑门可以推广到任意个输入值。

CMOS 晶体管

现代计算机由大量逻辑门构成，而逻辑门由晶体管构成。晶体管（transistor）是一个电子的可控开关，分为双极晶体管和金属-氧化物-半导体场效应管。

晶体管由“硅”构成，但纯硅的导电性很差。掺杂硅导电性很好，分为 n-型掺杂（砷）和p-型掺杂（硼）。

导电的原因：

  • n-型掺杂硅由于中央元素有富余电子，可在导体内自由移动，因此可形成电流。
  • p-型掺杂硅由于中央元素缺乏足够电子形成共价键，存在吸引电子的空穴，因此也会形成电流。

实际生产中通常将n型和p型半导体结合使用。

MOS管，即金属-氧化物-半导体晶体管。它的组成如下：

  • 底层：硅晶元衬底（substrate）
  • 顶层：导电栅极（gate）
  • 中间：二氧化硅绝缘层，形成电容

nMOS：

  • Gate = 0，截止（OFF），源极和漏极不连接。
  • Gate = 1，导通（On），源极和漏极之间通道连通。

pMOS：

  • Gate = 1，截止（OFF），源极和漏极不连接。
  • Gate = 0，导通（On），源极和漏极之间通道连通

nMOS晶体管能很好导通低电平，但导通高电平能力比较弱；pMOS晶体管能很好导通高电平，但导通低电平能力比较弱。

通常nMOS的源极接地（GND）， pMOS的源极连接电源（VDD）。同时提供两种类型晶体管的工艺称为互补型MOS工艺，即CMOS工艺。

有了这两种晶体管，就可以设计出 CMOS 逻辑门。

CMOS 非门

A P1 N1 Y
0 on off 1
1 off on 0

CMOS 与非门

A B P1 P2 N1 N2 Y
0 0 on on off off 1
0 1 on off off on 1
1 0 off on on off 1
1 1 off off on on 0

实际设计中，通常仅使用非门和与非门就可以构造出所有的逻辑门，这样设计的复杂度最低。

逻辑关系的描述

布尔代数

布尔代数是研究数字电路的数学基础。

基本概念

布尔代数中的变量取值只能为“真”（TRUE）或“假”（FALSE），其中 “1” 表示真，“0” 表示假。

三种基本逻辑运算：

运算 运算符 举例
与 $\cdot$ $A \cdot B$ 或 $AB$
或 $+$ $A + B$
非 $\overline{A}$ $\overline{A}$

变量与反变量：

  • 变量：使用 $A, B, \cdots$ 或 $a, b, \cdots$ 来表示，取值只能为 $0$ 或 $1$。
  • 反变量（变量的非）：变量上面有一条横线，$\overline{A}, \overline{B}, \cdots$。
  • 项：变量或它的反变量。

布尔表达式：适用于描述组合逻辑电路中输入与输出间的功能规范，也称逻辑函数，如 $S = F(A, B, C_{\text{in}})$，$C_{\text{out}} = F(A, B, C_{\text{in}})$

公理与定理

📝 备注

对偶规则

设 $F$ 为任意逻辑表达式，若将 $F$ 中所有运算符和常量作如下变换：

  • $\cdot \rightarrow +$，$+ \rightarrow \cdot$
  • $0 \rightarrow 1$，$1 \rightarrow 0$

则所得新的表达式为 $F$ 的对偶式 $F'$。

对偶是相互的，$F$ 和 $F'$ 互为对偶式。两个逻辑表达式 $F$ 和 $G$ 相等，则对偶式 $F'$ 和 $G'$ 也相等。例如：

$$A(B+C) = AB + AC \longrightarrow A + BC = (A + B)(A + C)$$

二进制量 如果 $B=0$，那么 $B \ne 1$ 如果 $B=1$，那么 $B \ne 0$
NOT $\overline{0} = 1$ $\overline{1} = 0$
AND/OR $0 \cdot 0 = 0$ $1+1 = 1$
AND/OR $1 \cdot 1 = 1$ $0+0 = 0$
AND/OR $0 \cdot 1= 1 \cdot 0 = 0$ $1 + 0 = 0 + 1 = 1$

最小项

最小项是一种特殊的乘积项（“与”项）：

  • $n$ 个变量逻辑函数的每个最小项，一定是包含 $n$ 个因子的乘积项。
  • 在各个最小项中，每个变量必须以原变量或反变量形式作为因子出现一次，而且仅出现一次。

最小项用 $m_i$ 表示，下标 $i$ 为使该最小项为 $1$ 的变量取值所对应的等效十进制数。

例如，最小项 $\overline{A}BC$ 值为 $1$ 的对应取值为 $0, 1, 1$，二进制数 $011$ 的等效十进制数为 $3$，则 $\overline{A}BC = m_3$。

从真值表中容易看出，每个最小项只有一组变量取值能使其值为 $1$ ，而其他各组取值该最小项皆为 $0$。由这种“与”函数真值表中 $1$ 的个数最少，而得名“最小项”。

最小项的性质：

  • 变量任取一组值，仅有一个最小项为 $1$，其他最小项为 $0$。
  • $n$ 个变量的全体最小项（共有 $2^n$ 个）之和恒为 $1$。
  • $n$ 个变量任意两个不同的最小项相与，结果恒为 $0$。
  • 两个相邻的最小项作“或”运算，可以合并成一项，并可以消去一个变量因子。

两最小项仅有一个变量因子不同，其他变量均相同，则两个最小项相邻。例如 $ABC + AB \overline{C} = AB$。

  • 任意 $n$ 变量的最小项，必定和其他 $n$ 个不同最小项相邻，即每一变量取反都是相邻项。

最大项

最大项是一种特殊的和项（“或”项）：

  • $n$ 个变量构成的每个最大项一定是包含 $n$ 个因子的“或”项。
  • 在各个最大项中，每个变量必须以原变量或反变量形式作为因子出现一次，而且仅出现一次。

最大项用 $M_i$ 表示，下标 $i$ 为使该最大项为 $0$ 的变量取值所对应的等效十进制数

例如，最大项 $\overline{A} + B + C$ 值为 $0$ 的 $A, B, C$ 的取值应为 $1, 0, 0$，二进制数 $100$ 所等效的十进制数为 $4$，所以 $\overline{A} + B + C = M_4$。

从真值表中可以看出，每个最大项只有一组变量取值能使其值为 $0$，而其他各组取值该最大项皆为 $1$。由这种“或”函数真值表中 $1$ 的个数最多，而得名“最大项”。

最大项的性质：

  • 变量任取一组值，仅有一个最大项为 $0$，其他最大项为 $1$。
  • $n$ 个变量的全体最大项（共有 $2^n$ 个）之积恒为 $0$。
  • $n$ 个变量任意两个不同的最大项相或，结果恒为 $1$。
  • 两相邻的最大项相“与”，可以合并成一项（等于相同因子之和），并可消去一个变量因子。
  • 任意 $n$ 变量的最大项，必定和其他 $n$ 个不同最大项相邻。

真值表与波形图

$n$ 个输入变量逻辑函数的真值表有 $2……n$ 行。当 $n$ 较大时，真值表将变得十分巨大。因此真值表只适用于描述变量数较少的逻辑函数。

逻辑函数输入变量的变化和输出变量的变化之间存在时间上的关联，因此可以通过波形图来描述输出变量对于输入变量的变化所产生的响应。

真值表与标准表示

标准与或式

标准与或式是由最小项之和构成的逻辑表达式。每个最小项都对应真值表中值为 $1$ 的一行，最小项之间通过或运算连接，与真值表一一对应。

因此，从标准与或式中可以直接判断哪些变量取值可以使表达式为 $1$。

任一逻辑函数都可以表达为最小项之和的形式，而且是唯一的。

标准或与式

标准或与式是由最大项之积构成的逻辑表达式。任一逻辑函数都可以表达为最大项之积的形式，而且是唯一的。

标准与或式和标准或与式的关系：

$$F = \sum_i m_i = \prod_{j \ne i} M_j$$

真值表与布尔表达式的转换

表达式转换为真值表：

  • 方法1：将变量的所有可能取值组合一一代入表达式进行计算
  • 方法2：将表达式转化为标准与或式
  • 方法3：根据函数式的逻辑含义，直接填表

真值表转换为表达式：

  • 方法1：根据最小项的性质，直接从真值表写出标准与或式。
  • 方法2：根据最大项的性质，直接从真值表写出标准或与式。
