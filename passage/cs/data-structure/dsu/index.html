数据结构：并查集

并查集（Disjoint Set Union，简称DSU，也叫Union-Find）是一种非常精巧的树形数据结构。它的核心用途是高效地处理不相交集合的合并与查询问题。

基本结构

并查集通常用数组（或哈希表）来实现，本质上是维护一个多棵树的森林，其中每棵树代表一个集合。

初始化

一开始，每个元素各自独立成一个集合，自己是自己的“根节点”。用数组parent来记录每个节点的父节点，parent[i] = i 表示 i 是根节点。

// 初始化：每个元素自成一个集合
int parent[MAXN];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        parent[i] = i;
    }
}

查找——追根溯源

给定一个元素 $x$，我们沿着它的父节点链一直向上找，直到找到根节点（即 parent[x] == x 的节点）。

1
2
3
4
5
6
7

// 查找：返回 x 所在集合的根节点
int find(int x) {
    while (parent[x] != x) {
        x = parent[x];
    }
    return x;
}

合并——两树相连

要将元素 $x$ 和 $y$ 所在的集合合并，先找到它们的根 rootX 和 rootY。如果根不同，就让其中一个根成为另一个根的父节点（例如 parent[rootX] = rootY）。

1
2
3
4
5
6
7
8

// 合并：把 x 和 y 所在的集合合并为一个集合
void unite(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if (rootX != rootY) {
        parent[rootX] = rootY;
    }
}

判断两个元素是否属于同一集合，只需比较它们的根节点是否相同：

1
2
3
4

// 判断 x 和 y 是否属于同一集合
bool same(int x, int y) {
    return find(x) == find(y);
}

优化

如果不做任何优化，树的高度无法得到控制：在最坏情况下（例如依次把元素 $1$ 合并到 $2$、元素 $2$ 合并到 $3$……），整棵树会退化成一条链。此时每次查找或合并都需要 $\mathrm{O}(n)$ 的时间，进行 $m$ 次操作的总复杂度为 $\mathrm{O}(mn)$，效率很低。

因此，需要通过下面两种优化来保持树的“矮胖”形态。

路径压缩

在查找的同时，把沿途经过的每个节点都直接挂到根节点上。这样下次再查找这些节点时，只需一步就能到达根节点，树会变得越来越扁平。

1
2
3
4

// 带路径压缩的查找
int find(int x) {
    return parent[x] == x ? x : parent[x] = find(parent[x]);
}

按秩合并

合并时总是把“矮”的树挂到“高”的树下面，避免树的高度无谓地增加。用数组 rank 记录以每个节点为根的树的“高度上界”（秩），两棵树秩相同的情况下，合并后根节点的秩加 $1$。

// 带按秩合并的合并
int rank[MAXN]; // 初始化为 0

void unite(int x, int y) {
    int rootX = find(x);
    int rootY = find(y);
    if (rootX == rootY) return;
    if (rank[rootX] < rank[rootY]) swap(rootX, rootY);
    parent[rootY] = rootX;
    if (rank[rootX] == rank[rootY]) rank[rootX]++;
}

按秩合并也可以换成“按大小合并”（把元素少的集合挂到元素多的集合下面），效果类似。

结论：

  • 只使用路径压缩或只使用按秩合并：$m$ 次操作的均摊复杂度为 $\mathrm{O}(m \log n)$；
  • 同时使用两种优化：$m$ 次操作的均摊复杂度为 $\mathrm{O}(m \cdot \alpha(n))$，其中 $\alpha(n)$ 是阿克曼函数的反函数，增长极其缓慢。对现实中可能出现的一切 $n$，$\alpha(n) \leqslant 4$，几乎可以看作常数。因此并查集的操作在实践上接近 $\mathrm{O}(1)$。

struct DSU {
    vector<int> parent, rank;

    DSU(int n) : parent(n + 1), rank(n + 1, 0) {
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
        }
    }

    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }

    void unite(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return;
        if (rank[rootX] < rank[rootY]) swap(rootX, rootY);
        parent[rootY] = rootX;
        if (rank[rootX] == rank[rootY]) rank[rootX]++;
    }

    bool same(int x, int y) {
        return find(x) == find(y);
    }
};

应用

冗余连接

给定一个 $n$ 个节点、$n$ 条边的无向图，其中多出来的那一条边会使图中出现环。逐条加入边，若某条边的两个端点已经连通，说明加入它就会形成环，这条边就是多余的边：

vector<int> findRedundantConnection(vector<vector<int>>& edges) {
    int n = edges.size();
    DSU dsu(n);
    for (auto& e : edges) {
        if (dsu.same(e[0], e[1])) return e;
        dsu.unite(e[0], e[1]);
    }
    return {};
}

省份数量

给定 $n$ 个城市之间的邻接矩阵，互相连通的若干城市组成一个省份。合并所有直接相连的城市后，统计根节点的个数即为省份数量：

int findCircleNum(vector<vector<int>>& isConnected) {
    int n = isConnected.size();
    DSU dsu(n);
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (isConnected[i][j]) dsu.unite(i + 1, j + 1);
        }
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (dsu.find(i) == i) cnt++;
    }
    return cnt;
}

Kruskal 最小生成树

将边按权值从小到大排序，依次尝试把每条边加入生成树：若边的两个端点已经连通，加入它就会形成环，跳过；否则合并这两个端点所在的集合。选满 $n-1$ 条边时，就得到了最小生成树。

struct Edge {
    int u, v, w;
};

int kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.w < b.w;
    });
    DSU dsu(n);
    int ans = 0, cnt = 0;
    for (const Edge& e : edges) {
        if (dsu.same(e.u, e.v)) continue;
        dsu.unite(e.u, e.v);
        ans += e.w;
        if (++cnt == n - 1) break;
    }
    return cnt == n - 1 ? ans : -1; // -1 表示图不连通
}

拓展

  • 带权并查集：在节点与父节点的边上维护权值（如相对关系），用于解决「食物链」（洛谷 P2024）这类需要刻画元素间关系的问题。
  • 可撤销并查集：用栈记录每次合并操作，支持按时间倒序撤销，常见于线段树分治等离线算法。
  • 维护集合大小：在根节点上记录集合的元素个数，合并时累加，可用于统计每个连通块的大小。
