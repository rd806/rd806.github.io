提取单一风格的字体

2026年9月15日星期二 阅读时长: 1 分钟
目录
  1. 准备文件
  2. 下载工具包
  3. 提取字体

下载的字体文件可能包含多种风格，实际上可能只需要其中一部分，如果直接打包进工程会让整个项目体积膨胀。提取字体文件中的单一风格（如 Thin 或 Medium），也称为字体格式转换或子集化。

具体方法取决于字体文件格式（TTF/OTF、TTC 集合、或可变字体）。下面以 ttf 文件为例说明。

准备文件

从网络下载含有多个风格的字体包，这里以 HarmonyOS_Sans 为例。

下载工具包

首先确认已存在 python 环境，安装 pip install fonttools

安装时可能出现：

1

Defaulting to user installation because normal site-packages is not writeable

这个提示不是错误，而是 pip 的安装位置警告：系统级的 Python 包目录（site-packages）当前用户没有写入权限，所以 pip 自动改为安装到你的用户目录下。

该警告通常没有影响，可通过以下命令确认：

1

python3 -m pip show fonttools

如果能看到版本信息，说明提取工具安装完成。

提取字体

假设待提取的字体文件名为 MyFont-VF.ttf，使用 instancer 命令提取特定权重：

1

fonttools varLib.instancer MyFont-VF.ttf wght=100 -o MyFont-Thin.ttf

这样在当前目录下将会生成仅包含 Thin 风格（即 wght=100 ）的字体文件 MyFont-Thin.ttf。

如果提示 Command not found，说明 ~/.local/bin 不在 PATH 里。可以采用以下方法解决：

1
2
3
4
5

# 临时加入
export PATH="$HOME/.local/bin:$PATH"

# 直接用模块方式调用
python3 -m fontTools.varLib.instancer MyFont-VF.ttf wght=100 -o MyFont-Thin.ttf
