MySQL是目前流行的数据库管理系统，使用SQL语法操作和管理。

准备工作

# 安装MYSQL
sudo apt-get install mysql-server

# 启动MySQL服务
sudo service mysql start

# 登录MySQL
mysql -u '用户名' -p '密码'

配置MySQL

首先使用命令

1

sudo mysql -u root

进入MySQL界面，然后操作

设置用户密码 

1
2
3

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的新密码';
FLUSH PRIVILEGES;
EXIT;

退出后以新的密码即可登录MySQL。

允许远程访问

在Shell中输入：

1

sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf

找到bind-address，将其修改为0.0.0.0或注释掉该行。

保存后重启服务：

1

sudo service mysql restart

创建新用户 

1
2
3

CREATE USER '新用户名'@'%' IDENTIFIED BY '新密码';
GRANT ALL PRIVILEGES ON *.* TO '新用户名'@'%' WITH GRANT OPTION;
FLUSH PRIVILEGES;

退出后以新的用户名和密码即可登录MySQL。

通用语法

  1. 单行或多行书写，以分号结尾。
  2. 可以使用空格/缩进。
  3. SQL语句不区分大小写，关键字建议大写。
  4. 单行注释：--注释内容或# 注释内容；多行注释：/* 注释内容 */。
  5. 其他参照SQL语言。
