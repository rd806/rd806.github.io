在GeoGebra中模拟函数插值

2026年10月17日星期六 阅读时长: 2 分钟

GeoGebra 内置了多项式插值命令。只需在代数区定义一组点，然后调用命令即可：

  • 在输入栏中定义点集，例如 points = {(-3, -14), (-1, 4), (1, 0), (3, 22)}。
  • 输入 Polynomial[points]。

GeoGebra 会自动计算并绘制出穿过这些点的插值多项式图形。但是这种方法无法感受到插值函数的构造过程，因此才有了以下内容。

上述方法的产生的插值函数与拉格朗日插值和牛顿插值的结果一定一致，因为通过 $n+1$ 个点的次数不超过 $n$ 的多项式是唯一的。如果发现偏差，那一定是有一步出错了。

拉格朗日插值

首先需要输出目标函数和插值区间 $[a,b]$。这里可以新建两个滑动条 $a$，$b$，目标函数定义为 $G(x)$。

构造插值节点

为了方便，这里使用等距节点。

在 GeoGebra 中输入命令：

1

xs = Sequence(a + k * (b - a) / n, k, 0, n)

这样会得到一个从 $a$ 到 $b$、共 $n+1$ 个等距数值的列表 $xs = \{a, a+d, a+2d, \cdots, b\}$

接着输入命令：

1

ys = Sequence(G(xs(k)), k, 1, n+1)

得到 $xs$ 对应的函数值列表 $ys$。

获得 $xs$ 和 $ys$ 后就可以得到插值节点，输入

1

points = Sequence((xs(k), ys(k)), k, 1, n+1)

得到点列 $points$。

生成插值函数

输入命令

1
2
3
4
5

L(x) = Sum(
  ys(i) * Product(
    If(j == i, 1, (x - xs(j)) / (xs(i) - xs(j))), j, 1, n+1
  ), i, 1, n+1
)

这就是拉格朗日插值函数

$$L_n(x) = \sum_{k=0}^{n} y_k l_k(x) $$

其中

$$l_k(x) = \prod_{0 \leqslant i \leqslant n, i \ne k} \frac{x-x_i}{x_k-x_i} $$

的表达。

牛顿插值

构造插值节点的步骤与拉格朗日法的一致，接下来构造差分表。

构造差分表

GeoGebra 代数区的命令不适用于运算存在递归的表达式，因此需要在表格区（数据区）实现。以下是具体步骤：

  • 在数据区第一列 A 输入序号 $0,1,\cdots,n$（$n$ 为最大允许的插值间隔数），代表该行对应的节点。
  • 数据区第二列 B 输入 =xs(Ak) （Ak 对应存放该行节点序号的单元格）；第三列 C 输入 =ys(Bk)。
  • 接下来的每一列对应各阶差分，在每个单元格输入对应的运算表达式计算相应的值（具体和 Excel 类似）。

生成插值函数

完成差分表后，按住 Ctrl 选择需要的系数，右键导出为列表，命名为 coeffs。

之后在代数区输入以下指令：

1
2
3
4

N(x) = coeffs(1) + Sum(
  coeffs(k+1) * Product(x - xs(j), j, 1, k),
  k, 1, n-1
)

即可得到牛顿插值函数。
