git简介

git 是一个开源的分布式版本控制系统（VCS），用于高效、快速地处理从小型到大型项目的所有内容管理。它由 Linus Torvalds（Linux 之父）于 2005 年创建，最初是为了更好地管理 Linux 内核开发。

基本概念 含义
仓库（Repository） 存储项目所有文件和历史记录的地方
工作区（Working Directory） 你电脑上实际看到的项目文件夹
暂存区（Index/Stage） 准备提交的更改区域，介于工作区和仓库之间
提交（Commit） 保存项目当前状态为一个版本
分支（Branch） 从主线上分出来的独立开发线，不影响主线
合并（Merge） 将分支的更改整合到另一个分支
远程仓库（Remote） 托管在网络上的仓库，如 GitHub、GitLab

撤销提交记录

在 Git 中撤销已提交的文件，主要看想要撤销到什么程度。以下是几种常见场景和对应的命令：

撤销最后一次提交

保留修改：撤销提交，但修改的文件会保留在暂存区。适合想重新修改提交信息或补充文件

1

git reset --soft HEAD~1

不保留修改:

1

git reset --hard HEAD~1

注意：这将会完全撤销提交，所有修改都会丢失

若要撤销特定文件的提交，则输入：

1

git reset HEAD^ -- <文件路径>

例如撤销 src/main.js 的最后一次提交：

1

git reset HEAD^ -- src/main.js

已经推送到远程仓库 

1
2
3
4
5

# 先本地撤销
git reset --soft HEAD~1

# 强制推送（需要权限，团队协作慎用）
git push --force origin <分支名>

更安全的方式：使用 git revert 保留历史记录

1
2

git revert HEAD
git push origin <分支名>

撤销中间的某次提交 

1
2
3
4
5

# 查看提交历史找到要撤销的 commit ID
git log --oneline

# 撤销指定提交（会生成新的撤销提交）
git revert <commit-id>

变更分支

若更改未push到远程仓库中，默认保存在本地工作文件夹的.git文件夹中，此时可以对分支进行任意的修改操作。

进入工程文件夹，在终端中输入

1

git log

此命令可以查看当前所有提交的具体信息，包括提交时间、作者、提交ID等。可以使用键盘的“↑”、“↓”键滚动，按q键退出。

选择需要更改的提交，复制它的ID。然后退出log，在终端中输入

1

git rebase -i 复制的提交ID

这样会打开一个Nano编辑器，在要删除的提交前加上#，然后Ctrl+O写入、回车、Ctrl+X保存。系统会自动变更分支结构。继续提交新的更改，变更完成。

⚠️ 警告

若要更改的提交已经推送到远程仓库，则需要在最后push时强制变更，输入

1

git pull <分支名> --force

注意：强制变更时应保证此时没有其他人员的提交，否则会导致分支出错。

Github的使用

Github是当前世界最大的开源网站库，使用git操作管理所有文件。

注册一个Github账号后即可在Github上免费创建和使用仓库，也可以加入其他开源项目的开发。

添加 SSH 密钥

一些情况下，使用git push时会提示网络连接超时。这时可以尝试使用SSH协议，为你的Github账户添加 SSH 密钥。

📝 备注

以下操作均在Linux系统下进行。

如果是Windows系统，则需要首先安装 Git Bash，然后在 Git Bash 中执行上述操作。

首先生成SSH密钥（如果尚未生成）：

1
2
3
4
5

# 引号中填写注册Github时的邮箱地址。
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

# 复制公钥内容
cat ~/.ssh/id_rsa.pub

然后将公钥添加到GitHub账户：登录GitHub，进入Settings → SSH and GPG keys → New SSH key，粘贴公钥并保存。

链接到远程仓库 

1
2
3
4
5
6
7

# 添加远程仓库
git remote add origin <repository-url>

# 推送到远程
git push -u origin main
# 或
git push -u origin master

远程仓库链接建议使用 SSH 格式，需要更改可以使用以下命令：

1
2
3
4
5

# 更改为 SSH 格式
git remote set-url origin git@github.com:{USERNAME}/{REPOSITORY}.git

# 更改为 HTTP 格式
git remote set-url origin https://github.com/{username}/{repository}.git

替换 USERNAME 和 REPOSITORY 为你的GitHub用户名和仓库名。

更改提交邮箱

GitHub 记录提交信息主要依据邮箱信息，必须提前在本地设置完成，提交才能被记录。

修改未来的提交

如果只是想更改从现在开始的提交邮箱，之前的提交保持不变，那么只需修改配置：

仅当前仓库：在项目目录下执行

1

git config user.email "你的新邮箱@example.com"

全局生效：加上 --global 参数

1

git config --global user.email "你的新邮箱@example.com"

验证：执行 git config user.email 检查是否设置成功。

修改最近一次提交（尚未推送）

如果刚提交完，发现邮箱错了，且还没有 push 到远程仓库，则执行：

1

git commit --amend --author="你的新用户名 <你的新邮箱@example.com>"
